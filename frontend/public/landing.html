Up and Running in 2 Minutes

Four steps from signup to live Playwright test results.

1

Sign Up & Get API Key

Sign up for a cloud account and generate an API key in Settings → API Keys.

# 1. Sign up at /signup
# 2. Go to Settings → API Keys
DASHBOARD_API_KEY=pd_sk_735ae732...
2

Install Reporter Package

Install the custom reporter package in your Playwright test repository.

npm i @christmasday/playwright-dashboard-reporter --save-dev
3

Connect playwright.config.ts

Add the reporter to your Playwright configuration file with your API key.

// playwright.config.ts
reporter: [
  ['@christmasday/playwright-dashboard-reporter', {
    url: 'https://playwright-dashboard.easytesting.app/api',
    apiKey: process.env.DASHBOARD_API_KEY,
  }]
]
4

Run Tests & Stream Results

Run tests and watch execution metrics stream live on the dashboard.

npx playwright test
# → live results at /dashboard
