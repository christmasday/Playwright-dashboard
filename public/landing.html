Up and running in minutes

Four steps from signup to live results.

1

Sign up & get API key

Sign up for a cloud account and generate an API key in Settings → API Keys.

# 1. Sign up at /signup
# 2. Go to Settings → API Keys
DASHBOARD_API_KEY=pd_sk_735ae732...
2

Install Reporter

Install the custom reporter package in your test project.

npm i @christmasday/playwright-dashboard-reporter --save-dev
3

Connect Playwright

Add the reporter to playwright.config.ts with your API key.

// playwright.config.ts
reporter: [
  ['@christmasday/playwright-dashboard-reporter', {
    url: 'http://localhost:3002/api',
    apiKey: process.env.DASHBOARD_API_KEY,
  }]
]
4

Run & watch

Results stream to the dashboard in real time.

npx playwright test
# → live at /dashboard
